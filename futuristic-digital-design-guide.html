05 / Copy & paste

Developer CSS kit

Salin konfigurasi di bawah untuk dipakai di proyek. Font diambil dari Google Fonts dan token sudah mencakup typography serta color palette.

design-system.css / FULL CONFIG
/* GOOGLE FONTS */
@import url('https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500;600;700&family=Orbitron:wght@400;500;600;700;800&family=Share+Tech+Mono&display=swap');

:root {
  /* FONT FAMILY */
  --font-heading: 'Orbitron', sans-serif;
  --font-body: 'DM Sans', sans-serif;
  --font-mono: 'Share Tech Mono', monospace;

  /* TYPE SCALE */
  --text-h1: clamp(2.5rem, 5vw, 4rem);
  --text-h2: clamp(2rem, 3.5vw, 2.75rem);
  --text-h3: clamp(1.5rem, 2.5vw, 2rem);
  --text-h4: clamp(1.25rem, 2vw, 1.5rem);
  --text-h5: 1.125rem;
  --text-large: 1.125rem;
  --text-base: 1rem;
  --text-small: 0.875rem;
  --text-caption: 0.75rem;

  /* INTERFACE */
  --text-navbar: 0.875rem;
  --text-button: 0.875rem;
  --text-label: 0.75rem;

  /* TECHNICAL */
  --text-data: 1.125rem;
  --text-code: 0.875rem;
  --text-metadata: 0.75rem;

  /* COLOR PALETTE */
  --color-primary: #5b63f1;
  --color-secondary: #faea1c;
  --color-accent-1: #ff614c;
  --color-accent-2: #e5d13e;
  --color-accent-3: #bb4b46;
  --color-light: #496af1;
  --color-dark: #152755;

  /* NEUTRAL UI */
  --color-bg: #f5f6fb;
  --color-surface: #ffffff;
  --color-ink: #17213c;
  --color-muted: #68738d;
  --color-border: #e3e7f0;
}

body {
  font-family: var(--font-body);
  font-size: var(--text-base);
  line-height: 1.6;
}

h1, h2, h3, h4, h5 {
  font-family: var(--font-heading);
  line-height: 1.2;
}

h1 { font-size: var(--text-h1); }
h2 { font-size: var(--text-h2); }
h3 { font-size: var(--text-h3); }
h4 { font-size: var(--text-h4); }
h5 { font-size: var(--text-h5); }

code, pre, .technical-data {
  font-family: var(--font-mono);
}

Implementation notes

Beberapa panduan supaya sistem tetap konsisten.

  • Gunakan Orbitron seperlunya; jangan untuk paragraf panjang.
  • Body text idealnya 16px dengan line-height 1.5–1.6.
  • Gunakan uppercase untuk label sistem, bukan semua teks.
  • Gunakan warna aksen secara hemat agar hierarki tetap jelas.
  • Uji kontras teks dan background, terutama untuk ukuran kecil.
Developer note: CSS pada bagian atas halaman adalah styling untuk dokumentasi ini. Blok design-system.css di atas merupakan konfigurasi ringkas yang bisa disalin ke proyek lu. Kalau proyek sudah punya file CSS utama, gabungkan bagian :root dan aturan elemen seperlunya.
