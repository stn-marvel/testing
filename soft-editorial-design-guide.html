05 / Developer handoff

Copy & paste CSS

Token CSS inti untuk langsung dipakai di proyek. Font di-load dari Google Fonts.

soft-editorial.css / DESIGN TOKENS
/* GOOGLE FONTS */
@import url('https://fonts.googleapis.com/css2?family=DM+Mono:wght@400;500&family=DM+Sans:wght@400;500;600;700&family=DM+Serif+Display:ital@0;1&family=Manrope:wght@400;500;600;700&display=swap');

:root {
  /* FONT FAMILY */
  --font-heading: 'DM Serif Display', Georgia, serif;
  --font-body: 'DM Sans', sans-serif;
  --font-ui: 'Manrope', sans-serif;
  --font-mono: 'DM Mono', monospace;

  /* TYPOGRAPHY */
  --text-display: clamp(3rem, 7vw, 6.5rem);
  --text-h1: clamp(2.5rem, 5vw, 4.5rem);
  --text-h2: clamp(2rem, 3.8vw, 3.25rem);
  --text-h3: clamp(1.5rem, 2.5vw, 2rem);
  --text-h4: 1.375rem;
  --text-h5: 1.125rem;
  --text-lead: 1.1875rem;
  --text-body: 1rem;
  --text-small: 0.875rem;
  --text-caption: 0.75rem;

  /* COLOR PALETTE */
  --color-paper: #F5F1EA;
  --color-cream: #EAE2D6;
  --color-ink: #302C28;
  --color-muted: #77716A;
  --color-sage: #A8B5A0;
  --color-dusty-rose: #C99591;
  --color-clay: #B97862;
  --color-mist-blue: #C7D5D8;
  --color-taupe: #B8A99A;
  --color-white: #FFFEFB;
  --color-line: #DED7CD;

  /* UI TOKENS */
  --radius-card: 4px;
  --radius-pill: 999px;
  --shadow-soft: 0 18px 50px rgba(48, 44, 40, .07);
}

body {
  margin: 0;
  background: var(--color-paper);
  color: var(--color-ink);
  font-family: var(--font-body);
  font-size: var(--text-body);
  line-height: 1.75;
}

h1, h2, h3, h4, h5 {
  font-family: var(--font-heading);
  font-weight: 400;
  line-height: 1.12;
}

h1 { font-size: var(--text-h1); }
h2 { font-size: var(--text-h2); }
h3 { font-size: var(--text-h3); }
h4 { font-size: var(--text-h4); }
h5 { font-size: var(--text-h5); }

button, nav, .ui-text {
  font-family: var(--font-ui);
}

.meta, time, .category {
  font-family: var(--font-mono);
}

Art direction notes

  • Gunakan ruang kosong yang cukup; jangan padatkan setiap section.
  • Serif paling efektif untuk headline, bukan semua komponen.
  • Batasi lebar paragraf sekitar 60–75 karakter per baris.
  • Pakai garis tipis dan border halus sebagai pemisah.
  • Gunakan foto dengan tone natural, grain lembut, dan pencahayaan hangat bila diperlukan.
