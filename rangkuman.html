1 Apa itu Program Ini?

Program ini adalah Simulasi Kehidupan Finansial berbasis web. Pengguna berperan sebagai karakter yang harus mengelola uang selama 10 hari. Mereka harus memilih antara menghabiskan uang (hiburan, belanja) atau mencari uang (kerja).

  • Fungsi: Melatih pengambilan keputusan keuangan sederhana.
  • Teknologi: Menggunakan React di dalam Python notebook agar interaktif.
  • Kenapa React? Karena React secara otomatis memperbarui tampilan (UI) saat data (uang/hari) berubah, membuat simulasi terasa hidup tanpa perlu reload halaman.

O. Main App Component (Otak Program)

Ini adalah induk semua komponen. Tempat "State Management" utama berada.

  • gameState: Menyimpan tahap game ('SETUP', 'PLAYING', 'RESULT').

App Component State
const App = () => {
  const [gameState, setGameState] = useState('SETUP');
  const [currentBalance, setCurrentBalance] = useState(0);
  
  // Logika utama ada di sini
  return ( ... );
};

Konsep State adalah inti React. Ketika currentBalance berubah, React otomatis merender ulang (menggambar ulang) angka di layar tanpa kita menyuruh manual.

P. useEffect (Side Effects)

Fungsi yang berjalan otomatis saat terjadi perubahan.

useEffect Hook
useEffect(() => {
  const dataToSave = { user, currentBalance, day };
  localStorage.setItem('save', JSON.stringify(dataToSave));
}, [user, currentBalance, day]); // Dependency Array
  • Fungsi: Menyimpan data ke localStorage browser.
  • Dependency Array: Kode di dalam hanya jalan jika variabel di kurung siku berubah. Ini mencegah loop tak terbatas.
  • Hasil: Jika browser di-refresh, game tidak hilang (Fitur Save).

Sistem kejutan dalam game.

Random Logic
const triggerEvent = Math.random() < 0.3;
const event = RANDOM_EVENTS[Math.floor(Math.random() * RANDOM_EVENTS.length)];

5 Konsep Dasar Wajib Pahami

Variable

Seperti kotak penyimpanan bertanda. let saldo = 100;

Function

Resep atau mesin kecil. Anda masukkan bahan (input), mesin mengolah, lalu mengeluarkan hasil (output).

Component

Lego digital. Potongan kode UI yang bisa dipasang-pasang. Contoh: Header, Button.

State

Memori jangka pendek aplikasi. Jika State berubah, layar berubah. Analoginya: Papan skor yang update real-time.

Props

Pesan yang dikirim dari komponen induk ke anak. Analoginya: Surat yang diberikan orang tua ke anak.

Event

Aksi user. Contoh: onClick (klik), onChange (ketik).

6 Kenapa Program Ini Bagus?

  • Modular Component

    Kode tidak berantakan di satu tempat. Setiap bagian (History, Setup, Result) dipisah, jadi mudah diperbaiki.

  • Persistent Save

    Menggunakan localStorage, user bisa menutup browser dan kembali lagi tanpa kehilangan progres.

  • Responsif & Interaktif

    Dibuat dengan mobile-first approach, terasa seperti aplikasi native di HP.

7 Poin Presentasi

"Saya menggunakan React" karena framework ini memungkinkan pembuatan antarmuka yang dinamis. Saat saldo berubah, angka di layar terupdate otomatis tanpa reload halaman.
